IPA_Python is a compact utility for reporting a device's current public and private IP addresses through Telegram, useful for small servers, Raspberry Pi systems and remote devices.

01 Project overview
01

Highlights

simple script
  • Detects internet connectivity
  • Retrieves the current public IP address
  • Finds local/private IP addresses
  • Sends a readable Telegram notification
  • Linux-oriented with a socket fallback when the ip command is unavailable
  • Minimal dependencies and easy manual execution
02

Typical use

network utility

Use case Run it when a device starts or on demand to receive the machine's current network addresses in Telegram.

Platforms Primarily Linux, with a socket-based fallback for systems such as macOS.

03

Credential hygiene

security

Important: keep real Telegram bot tokens and chat identifiers private. Review the repository configuration before deploying the script on a public or shared system.

Italiano

IPA_Python è una piccola utility che comunica tramite Telegram gli indirizzi IP pubblici e privati correnti di un dispositivo, utile per piccoli server, sistemi Raspberry Pi e dispositivi remoti.

English

IPA_Python is a compact utility for reporting a device's current public and private IP addresses through Telegram, useful for small servers, Raspberry Pi systems and remote devices.

Python 3.8+ Telegram Networking Linux/macOS

01 Panoramica / Project overview
01

Funzioni principali / Highlights

script semplice / simple script
Italiano
  • Verifica la connettività Internet
  • Recupera l'indirizzo IP pubblico corrente
  • Individua gli indirizzi IP locali e privati
  • Invia una notifica Telegram leggibile
  • Orientato a Linux, con fallback socket quando il comando ip non è disponibile
  • Dipendenze minime ed esecuzione manuale immediata
English
  • Detects internet connectivity
  • Retrieves the current public IP address
  • Finds local/private IP addresses
  • Sends a readable Telegram notification
  • Linux-oriented with a socket fallback when the ip command is unavailable
  • Minimal dependencies and easy manual execution
02

Utilizzo tipico / Typical use

utility di rete / network utility

Italiano Può essere eseguito all'avvio del dispositivo o su richiesta per ricevere su Telegram gli indirizzi di rete correnti. È pensato principalmente per Linux, con un fallback basato su socket per sistemi come macOS.

English Run it when a device starts or on demand to receive the machine's current network addresses in Telegram. It primarily targets Linux, with a socket-based fallback for systems such as macOS.

Protezione delle credenziali / Credential hygiene

sicurezza / security

Italiano Importante: mantieni privati i token reali dei bot Telegram e gli identificativi delle chat. Controlla la configurazione del repository prima di distribuire lo script su un sistema pubblico o condiviso.

English Important: keep real Telegram bot tokens and chat identifiers private. Review the repository configuration before deploying the script on a public or shared system.

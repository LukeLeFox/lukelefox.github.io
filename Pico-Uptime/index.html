01 Project overview
01

Highlights

stable
  • HTTP/HTTPS, TCP and ICMP monitoring with RTT
  • Responsive low-memory web dashboard
  • Telegram multi-chat notifications and per-target alert routing
  • Persistent polling thresholds and JSON configuration
  • Basic Auth protection and Wi-Fi recovery
  • Designed for microcontroller memory constraints
02

Target hardware

Pico W

Hardware Raspberry Pi Pico W with a recent MicroPython build and 2.4 GHz Wi-Fi.

Design No database or heavy web framework: the project is intentionally compact and autonomous.

03

Monitoring and alerts

network

Checks Monitor HTTP/HTTPS endpoints, TCP services and ICMP reachability with configurable polling thresholds.

Telegram Route transition alerts to one or more chats, with retry logic and per-target notification settings.

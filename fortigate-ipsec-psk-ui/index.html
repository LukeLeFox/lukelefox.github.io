01 Project overview
01

Highlights

administrative tool
  • Manual FortiGate connection configuration
  • Lists IPsec Phase 1 tunnels
  • Retrieves information through the FortiGate REST API
  • No credential persistence or local configuration database
  • Supports VDOM-aware administrative workflows
  • Designed for temporary, controlled administrative use
02

Security scope

trusted operators

Do not expose this application publicly. It handles sensitive administrative information and is intended for localhost or otherwise tightly controlled environments operated by authorized administrators.

03

Architecture

stateless

Backend Python 3.10+, Flask and requests.

Principle No offline decryption or reverse engineering: the UI acts as a frontend to behavior exposed by the FortiGate API and the privileges of the authenticated administrator.

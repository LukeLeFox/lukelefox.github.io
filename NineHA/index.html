NineHA brings a native Home Assistant experience to devices stuck on iOS 9, with a UIKit Lovelace-style dashboard, live updates and support for both iPad and iPhone legacy hardware.

01 Project overview
01

Highlights

experimental
  • Manual token authentication and experimental OAuth flow
  • Native UIKit dashboard plus optional original Lovelace WebView
  • Live updates over WebSocket with REST fallback
  • Layouts for masonry, grid, sections and conditional content
  • Native adapters for multiple standard and custom card types
  • Responsive dark interface for legacy iPad and iPhone screens
02

Prebuilt ARMv7 IPA

0.7.7

Release A precompiled ARMv7 IPA is published with the project release for compatible legacy devices.

Tested Development has been tested on a first-generation iPad mini and iPhone 4S.

03

Home Assistant integration

native client

Dashboard Rebuilds key Lovelace concepts with native UIKit components instead of relying entirely on modern browser features.

Security Saved app tokens are kept in the iOS Keychain; HTTPS or a VPN is recommended when possible.

$ NineHA is an independent experimental project and is not affiliated with Home Assistant or Nabu Casa.

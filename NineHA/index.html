01

Funzioni principali / Highlights

sperimentale / experimental
Italiano
  • Autenticazione con token manuale e flusso OAuth sperimentale
  • Dashboard UIKit nativa e Lovelace originale opzionale in WebView
  • Aggiornamenti live tramite WebSocket con fallback REST
  • Layout masonry, grid, sections e contenuti conditional
  • Adattatori nativi per diverse card standard e personalizzate
  • Interfaccia scura responsiva per i vecchi schermi iPad e iPhone
English
  • Manual token authentication and experimental OAuth flow
  • Native UIKit dashboard plus optional original Lovelace WebView
  • Live updates over WebSocket with REST fallback
  • Layouts for masonry, grid, sections and conditional content
  • Native adapters for multiple standard and custom card types
  • Responsive dark interface for legacy iPad and iPhone screens

03

Integrazione Home Assistant / Home Assistant integration

client nativo / native client

Italiano Ricostruisce i concetti principali di Lovelace con componenti UIKit nativi invece di dipendere interamente dalle funzioni dei browser moderni. I token salvati vengono conservati nel portachiavi iOS; quando possibile sono consigliati HTTPS o una VPN.

English Rebuilds key Lovelace concepts with native UIKit components instead of relying entirely on modern browser features. Saved app tokens are kept in the iOS Keychain; HTTPS or a VPN is recommended when possible.

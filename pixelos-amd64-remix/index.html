01 Project overview
01

Highlights

usable
  • Adds the Raspberry Pi Debian archive with a dedicated keyring
  • Keeps Debian as the base system using conservative APT pinning
  • Installs Raspberry Pi Desktop / RPD packages on amd64
  • Uses a stable X11 rpd-x session by default
  • Can migrate networking to NetworkManager when appropriate
  • Includes diagnostics and an installation report
02

Target environment

Debian 13

Base Clean Debian 13 Trixie amd64, ideally starting from a minimal or server-style installation.

Session The current stable target is rpd-x on X11; Wayland components may be installed but are not the default.

03

Project scope

unofficial

This is an unofficial community experiment. It does not produce an official Raspberry Pi OS image and is not affiliated with or endorsed by Raspberry Pi Ltd. or Debian.

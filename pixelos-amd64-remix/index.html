01 Panoramica / Project overview
01

Funzioni principali / Highlights

utilizzabile / usable
Italiano
  • Aggiunge l'archivio Debian di Raspberry Pi con un keyring dedicato
  • Mantiene Debian come sistema di base tramite pinning APT conservativo
  • Installa i pacchetti Raspberry Pi Desktop / RPD su amd64
  • Usa per impostazione predefinita una sessione X11 rpd-x stabile
  • Può migrare la rete a NetworkManager quando appropriato
  • Include diagnostica e un rapporto di installazione
English
  • Adds the Raspberry Pi Debian archive with a dedicated keyring
  • Keeps Debian as the base system using conservative APT pinning
  • Installs Raspberry Pi Desktop / RPD packages on amd64
  • Uses a stable X11 rpd-x session by default
  • Can migrate networking to NetworkManager when appropriate
  • Includes diagnostics and an installation report
02

Ambiente di destinazione / Target environment

Debian 13

Italiano Debian 13 Trixie amd64 pulito, preferibilmente partendo da un'installazione minima o server. La destinazione stabile corrente è rpd-x su X11; i componenti Wayland possono essere installati ma non sono predefiniti.

English Clean Debian 13 Trixie amd64, ideally starting from a minimal or server-style installation. The current stable target is rpd-x on X11; Wayland components may be installed but are not the default.

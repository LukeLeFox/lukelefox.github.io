Italiano

NineFin è un client Jellyfin nativo creato specificamente per i vecchi iPhone e iPad con iOS 9. È scritto in Objective-C con Theos ed è destinato all'hardware ARMv7 a 32 bit.

English

NineFin is a native Jellyfin client built specifically for legacy iPhone and iPad devices running iOS 9. It is written in Objective-C with Theos and targets 32-bit ARMv7 hardware.

01

Jellyfin su hardware Apple legacy / Jellyfin on legacy Apple hardware

iOS 9

Italiano Un'esperienza Jellyfin nativa pensata per riportare lo streaming su dispositivi legacy come iPhone 4S e vecchi iPad con iOS 9, senza dipendere da un browser moderno o da un client App Store corrente.

English A native Jellyfin experience for legacy devices such as the iPhone 4S and older iPads, without depending on a modern browser or a current App Store client.

English
  • Jellyfin login with sessions and credentials stored in the iOS Keychain
  • Multiple saved servers and selectable default server
  • Continue Watching, Next Up, recent movies and recent series
  • Movies, shows, seasons and episodes
  • Global search and favorites
  • Native HLS playback with configurable streaming quality
  • Playback progress synchronization and watched-state handling
  • Audio-track and subtitle selection

Scarica l'IPA precompilata / Download prebuilt IPA

GitHub Releases

Italiano Le release di NineFin includono IPA precompilate, quindi la compilazione dai sorgenti è facoltativa. L'installazione su dispositivi iOS 9 legacy richiede un metodo di sideload compatibile; i test sono stati eseguiti su un dispositivo jailbroken con AppSync Unified. Apri l'ultima release ↗

English Prebuilt IPA files are published with NineFin releases, so compiling from source is optional. Installation on legacy iOS 9 hardware requires a compatible IPA sideload method; testing used a jailbroken device with AppSync Unified. Open the latest release ↗

current_release=0.7.2
bundle_id=dev.luke.ninefin
deployment_target=iOS 9.0
architecture=armv7
package=IPA
04

Compila dai sorgenti / Build from source

Theos
$FINALPACKAGE=1 make package

Italiano Richiede Theos con SDK iOS 9.2. Il progetto mantiene intenzionalmente le impostazioni di distribuzione legacy; cambiare SDK, deployment target o architettura può compromettere la compatibilità.

English Requires Theos with an iOS 9.2 SDK. The project intentionally keeps its legacy deployment settings; changing the target SDK, deployment target or architecture may break compatibility.
